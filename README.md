# 聚在一起 · Party Playground (MVP 0.1)

**2–10 人的线下聚会游戏 App**。采用深色霓虹 / 可爱卡通形象；所有游戏尽量一部手机即可玩。

## 已实现

- 首页：创建聚会、快速玩一局、继续未完成聚会
- 聚会创建：人数 2–10、玩家昵称、手机主持或指定玩家主持。**没有单独的场景与气氛设置步骤**。
- 聚会房间：共享玩家名单、动态推荐、积分榜、游戏切换、结束聚会
- 游戏库：类型筛选、人数适配、快速选择
- 可玩的首版：真心话大冒险、谁是卧底、饭桌狼人杀、秘密任务、谁最有可能、默契挑战、海龟汤
- 私密查看身份、轮流传递手机、游戏倒计时（部分游戏）、手动判定、分数及结算、聚会历史和战报
- localStorage 本机保存游戏记录（刷新保留聚会与战报）

## 启动开发

需要 Node.js 20.19+ 或 22.12+：

```bash
npm install
npm run dev
```

生产构建：`npm run build`。Vercel 从 GitHub 导入本仓库后使用 Vite 预设，默认 `npm run build` 和 `dist`。

## MVP 边界

- 不需要账号，数据仅保存在当前浏览器；没有跨设备实时房间同步。
- 手机主持指的是流程引导、计时和提示；不是实际 AI 语音主持。真人主持可从已录入的玩家中选择。
- 饭桌狼人杀的行为完成情况需要玩家/主持人手动确认，系统**不能自动识别真实动作**。
- 身份发放和任务卡请轮流传递手机，不要让其他玩家窥视。
- 首版是产品验证包，正式上线还需多人测试、内容审核及数据备份。

## GitHub + Vercel

1. 在 https://github.com/new 创建一个新的空仓库（不要勾选自动创建 README）。
2. 将项目文件推送到 `main` 分支。
3. 在 https://vercel.com/new 授权 GitHub 并导入该仓库，Framework Preset 选择 `Vite`。
4. 点击 Deploy；以后向 `main` push 会自动触发重新部署。


## V0.2 定稿视觉重构（2026-10-15）

- 遵照用户确认的九屏赛博朋克设计稿，不变更主配色和页面流程。
